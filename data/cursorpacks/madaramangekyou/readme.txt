Madara Mangekyou Sharingan Set
==============================

Author: Hakku_

Notes:
This cursor has an animated design, created for Naruto fans.
In cursorFx version 2.16 the animations work perfectly.
Inside the download file there are 18 cursors.
I recommend adjusting the cursor to the size you want.

Este cursor tiene un diseño animado, creado para los fans de Naruto.
En cursorFx version 2.16 las animaciones funcionan perfectamente.
Dentro del archivo de descarga hay 18 cursores.
Recomiendo ajustar el cursor al tamaño que deseen.

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Madara Mangekyou Sharingan Set' from the Scheme dropdown
